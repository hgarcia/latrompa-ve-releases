# LaTrompa ve releases

Public macOS app downloads and release notes for **LaTrompa ve**. Application source code is maintained in a separate private repository.

[Download the latest release](https://github.com/hgarcia/latrompa-ve-releases/releases/latest)

Download the ZIP, extract **LaTrompa ve.app**, quit an older running copy, and replace the installed app. Requires an Apple silicon Mac running macOS 14 or newer. The app is ad hoc signed. Each release includes a SHA-256 checksum.

This repository contains release metadata and packaged applications only. The automatic GitHub source archives contain only the files in this public repository, not the editor source code.
